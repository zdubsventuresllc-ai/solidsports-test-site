★ THE SYSTEM

Brand mechanics

Solid isn't a look — it's a set of collector mechanics. The visual identity exists to serve these six rules.

EDITIONSNumbered 001, 002, 003… Always 200 units. Never reprinted.
CARDSEvery bat ships with its numbered card. Same serial as the bat — 047/200.
CAUSESOne cause per edition. $25 per bat. Totals published — "receipts on file."
CHASE CARDThe next edition's cause is voted on by current edition owners.
LANGUAGEYou don't buy a bat. You pull it. "PULL NO. 048 →"
THE SETThe archive is a card binder. The set isn't done until the cause is.
